## Overview

Full-screen audio player (`player` in the design handoff `Docs/design_handoff_innerlamp/`) — the
expanded version of the Reader's sticky play bar: themed radial background (`--il-pl-bg`), header
"Đang nghe" + "Mục lục" pill, a circular lamp artwork, the track title/subtitle, a progress bar
with elapsed/remaining times, seek (±15s / +30s) around a 72pt play/pause button, and two option
rows — playback speed ("0.75×"…"1.5×") and sleep timer ("Tắt" / "15p" / "30p" / "Hết bài") — plus a
footnote that changes with the selected sleep option.

`ILPlayerCoordinator` is a leaf screen: `ILReaderCoordinator` (Reader's "1.0×" speed button) and
`ILSutraDetailCoordinator` (SutraDetail's "Mở trình phát" action) both push it via their existing
`.openPlayer` nav event. It has no delegate — back pops and `finish()`es.

## Navigation events

- `.back` — header back chip (Input `backTapped`): `ILPlayerCoordinator` pops and `finish()`es.
- `.openTableOfContents` — "Mục lục" pill (Input `tableOfContentsTapped`): intended to open the
  chapter list (`detail` / `SutraDetail`); currently a TODO in `ILPlayerCoordinator`.

## Known gaps / not implemented yet

- **No real audio** — play/pause and seek only mutate in-memory state (the same limitation as the
  Reader). `ILPlayerUseCaseImpl` notes that real playback must drive `AVAudioPlayer` / a shared
  audio service once sutra audio files exist.
- **Mock catalog has only Kinh Pháp Cú** — other library sutras (Vu Lan, A Di Đà, Chú Đại Bi) have
  no audio data; an unknown id falls back to the first track.
- **"Mục lục" is not wired** — opening the chapter list from the player needs a navigation decision
  (the player is pushed on top of the reader/detail stack), left as a TODO.
- **Progress bar reuses `ILLinearProgressBarView`** — its fill is `gold → goldDeep` (5pt), while the
  design uses a `goldBright → goldOnDark` gradient (4pt); kept as a minor fidelity deviation to
  avoid a near-duplicate component.
- Not visually verified on simulator/device: build + unit tests pass, but the layout and dark mode
  have not been inspected in practice.
