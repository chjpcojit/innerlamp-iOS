## Overview

Màn "Chi tiết ngày âm" (`lunar` trong design handoff `Docs/design_handoff_innerlamp/`) — hiển thị
trọn bộ dữ liệu lịch âm của 1 ngày dương: ngày/tháng/năm âm lớn ở hero, pill "loại ngày"
(Hoàng đạo/Hắc đạo/Rằm/Mùng Một), dòng lời khuyên theo ngày, bảng Can Chi (Ngày · Tháng · Năm ·
Dương lịch), thẻ "Ngày [Cát/Hung]" (đánh giá ngày + thang 5 bậc + việc nên làm/kiêng cữ), phần
"Ngũ hành & nạp âm", câu kinh trong ngày, 6 giờ hoàng đạo, tuổi xung khắc và hướng xuất hành
(Hỷ thần / Tài thần). Mọi số liệu tính thuần bằng `ILLunarCalendar` từ ngày dương truyền vào.

`ILHomeCoordinator` sở hữu màn này — chạm thẻ âm lịch lớn ở Trang chủ → `ILHomeNavEvent.openLunarDayDetail(date:verse:)`
(mang ngày dương đang chọn). Màn là lá, nút ‹ pop về Trang chủ.

## Known gaps / not implemented yet

- **Ảnh bìa hero là placeholder** — prototype dùng `image-slot` (ảnh chùa/trăng/hoa sen). Chưa có
  ảnh thật nên thay bằng gradient `--il-sunk2 → --il-tint → --il-canvas` (khớp ghi chú
  "Ảnh chùa/sự kiện hiện là gradient tối; cần ảnh thật từ phía sản phẩm" ở README design handoff).
- **Verse of the day**: when opened from the Home hero card, the screen shows the same Core Data
  quote as the card (passed via `openLunarDayDetail(date:verse:)`). When opened from the Lunar
  Calendar (no verse passed), it loads the fixed quote of that date from Core Data
  (`ILSutraQuoteUseCase.quote(for:)`, day-of-year rotation). The static content (4 verses, index
  `(lunar day + lunar month) % 4`) is only shown while that load runs or if it fails.
- **Thẻ "Ngày [Cát/Hung]" dùng đánh giá chung** (không cá nhân hoá theo ngày sinh) — khớp design
  handoff. Cá nhân hoá trước đây (Trạch cát theo bản mệnh) đã gỡ để về đúng prototype.
- **Con giáp dùng emoji** (`🐀`…`🐖`) làm icon — chưa có bộ icon vector riêng.
- **Tên Can Chi / hướng / nạp âm / ngũ hành chỉ mới có bản tiếng Việt** trong `vi.json` — các ngôn
  ngữ còn lại (English/中文) chưa dịch, sẽ fallback về key.
- **Chưa kiểm tra bằng mắt trên simulator/thiết bị**: unit test đã pass, build OK; layout
  (thẻ almanac, 3 ô ngũ hành, hướng xuất hành 2 cột, dark mode và transition header) vẫn cần xem
  thực tế.
