## Overview

"Thắp đèn" and "Vườn đèn": the user lights a symbolic lamp (kind, intention, dedication target,
optional vow, 1/7/21/49 days), watches it ignite, then sees it in the garden grid with a per-kind
filter and "Xem thêm đèn" paging. `ILLightLampCoordinator` is a child of `ILHomeCoordinator` and
owns both screens; the entry is Home's suggested-session row of kind `offering` ("Thắp đèn — Vu
Lan"). Data is local-only (Core Data); there is no API. Spec: `Docs/Specs/LightLamp/`.

## Navigation events

Lighting (`ILLightLampNavEvent`):
- `.back` — pop and `finish()`.
- `.openGarden` — header "Vườn đèn" or the completion action "Vào vườn đèn"; push the garden.

Garden (`ILLampGardenNavEvent`):
- `.back` — pop to the lighting screen.
- `.openLighting` — header "Thắp đèn"; replace the garden (and the old lighting screen) with a fresh form.
