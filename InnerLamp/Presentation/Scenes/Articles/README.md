## Overview

The "Tất cả bài viết" (All articles) screen — a paginated list of every Dharma article, reachable
via the "Xem tất cả" link in the "Bài viết Phật pháp hay" section on Home. It shows a sticky header
with a count subtitle ("5 / 60 bài"), a vertical list of article cards, and a load-more footer that
reveals more articles as the user scrolls near the bottom. Tapping a card opens the existing
Article detail screen (`ILArticleCoordinator`). Owned by `ILHomeCoordinator`; `ILArticlesCoordinator`
manages its own stack (list → article detail).

## Navigation events

- `ILArticlesNavEvent.back` — pop the list screen and `finish()`.
- `ILArticlesNavEvent.openArticle(id:)` — push the Article detail screen for that article id.

## Known gaps / not implemented yet

- No search / category filter / sort — the API takes only `page`.
- A failed first page leaves an empty list (no retry control); re-entering the screen retries.
- No UI test — not requested.
