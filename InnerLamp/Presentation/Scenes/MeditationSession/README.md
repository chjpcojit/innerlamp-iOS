## Overview

Phiên thiền (design handoff screen `session`) — the immersive sitting screen: a countdown inside a
breathing ring (4s in / 6s out, rings scale 1 → 1.12), a Vietnamese breath cue with its English
line (guided sessions only), and a transport row (leave · pause/resume · end) plus an
"end early" link. It is pushed by `ILMeditationSetupCoordinator` onto the practice-flow stack it
presents modally, after the user taps "Bắt đầu · N phút" (guided) or "Ngồi im lặng" (silent) on
Chuẩn bị thiền. The next screen, Hoàn thành (`done`), is not built yet.

## Navigation events

- `.goBack` — header back or the leading ghost button: pops back to Chuẩn bị thiền, `finish()`.
- `.finished(elapsedSeconds:)` — countdown reached zero, or the stop button / "Kết thúc sớm" was
  tapped, and `recordSession` returned: forwarded via `ILMeditationSessionCoordinatorDelegate` to
  `ILMeditationSetupCoordinator`, which currently logs a TODO and closes the practice-flow modal.

## Known gaps / not implemented yet

- **Hoàn thành (`done`) screen not built** — on finish the whole practice modal is dismissed.
- **`recordSession` is a stub** — the sit is not saved to the practice log (streak, weekly minutes,
  mix); needs a local Repository, out of scope for il-screen-builder.
- **Bells are single strikes** — `ILPracticeSoundPlaying.playBell()` is played once at start and
  once at the end; the design's "3 tiếng khánh" (three strikes) and the "every 5 minutes"
  interval bell from Chuẩn bị thiền are not scheduled. No voice guidance / background sound
  ("Mưa hiên chùa") audio exists yet.
- **Countdown is foreground-only** — it is driven by a main-run-loop `Timer`, so time spent with the
  app in the background or the device locked is not counted. A wall-clock/`Date`-based elapsed
  time (and a background audio session) would be needed for a locked-screen sit.
- **Silent mode hides the breath cue text**; the ring still breathes. The design only shows the
  guided variant, so this is an interpretation.
- Edge-swipe back pops the screen without going through `.goBack`, so the coordinator is not
  `finish()`ed in that case (same as `Mala`).
- No UI test — not requested. The screen was verified by build + unit tests only, not visually on
  a simulator.
