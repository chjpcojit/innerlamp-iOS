## Overview

Settings screen (prototype screen `settings`, "Cài đặt"): a pushed screen inside the "Tôi" tab
(owned by `ILProfileCoordinator`), reached via the Profile menu's "Cài đặt" row. Shows an account
card (avatar + name + "Pháp danh … · SĐT"), then four grouped sections — Thời khóa (bell reminder
switch, fast-day reminder switch, bell sound), Hiển thị & ngôn ngữ (scripture font-size slider,
bilingual switch, dark-mode value), Nội dung & trợ giúp (downloads / language / help chevrons),
Riêng tư (hide journal switch, export data) — and a footer (version + legal + offline status link).
Design: prototype screen `settings` (`Docs/design_handoff_innerlamp/`). No spec under
`Docs/Specs/Settings/` yet.

## Known gaps / not implemented yet

- All data is mock (`ILSettingsUseCaseImpl.getSettings()`) — settings, bell times, download counts
  and account info need a persistence/API contract. Toggling a switch updates the in-memory
  `ILSettingsStateModel` only; it is not persisted (no `ILSettingsRepository` yet).
- "Chế độ tối" shows a mock `.system` label and does not read/write `ThemeService`; it will sync
  once the `lang` screen (and its theme wiring) is built.
- The font-size slider is a continuous 0…1 value and is not yet connected to the scripture reader's
  actual font scaling.
- The font-size slider uses `ILTypography.scriptureBodyTiny` (12px) and `scriptureBodyLarge` (20px)
  for its "A" previews — visual QA against the prototype's 12/20px is pending.
- The prototype's 4px left inset on section eyebrows is not reproduced (eyebrows align with cards,
  matching the rest of the app).
- `appVersion` is a mock "1.4"; it should read `CFBundleShortVersionString` when wired for real.
