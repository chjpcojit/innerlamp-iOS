# Stats

## Overview

"Tiến trình tu tập" (prototype key `stats`) — practice progress over the last 12 weeks: streak
featured card with the next milestone, total-time and usual-sit-time tiles, a 12-week duration bar
chart, the practice-mix breakdown, and a CTA card to the mindfulness bell reminder. Child screen of
the Me tab: `ILProfileCoordinator` pushes it when the "Nhật ký 12 tuần qua" heatmap card is tapped;
it pops back on the nav bar's back chip. Bottom nav is hidden while it is on screen.

## Navigation events

- `goBack` — nav bar back chip; pops and finishes the coordinator.
- `openReminder` — "Giữ chuỗi ngày bằng chuông nhắc" card; TODO until the mindfulness bell reminder (`remind`) screen exists.

## Known gaps / not implemented yet

- Real data: `ILStatsUseCaseImpl.getStats()` returns sample data — no confirmed stats API/local store yet.
- `openReminder` has no destination yet.
- Only the Profile heatmap card leads here; other entry points in the handoff (Home streak card, Journal detail "Xem tiến trình", Awards bottom button) are not wired — those screens either lack a stats event or are not built.
- No error/offline state rendering (`.failure` is a TODO) — irrelevant until a real Repository exists.
- No UI test — not requested.
