## Overview

Chuông mõ (the `bell` screen in the design handoff) — a full-screen immersive practice tool for
keeping rhythm while chanting / reciting / prostrating: tap the pad to strike a wooden fish or
ring a bell, pick a preset (Tụng kinh / Niệm Phật / Lạy sám hối / Ngồi thiền / Chỉ gõ mõ), switch
mode (Mõ / Chuông / Mõ + chuông), set the rhythm (bpm / bell interval), auto-ring the bell every
10 / 27 / 108 strikes, and run a steady rhythm or an accelerating "dồn mõ" roll. It supports light
+ dark mode via the `--il-med-*` token set. `ILBellCoordinator` is created by `ILHomeCoordinator`
(the "Chuông mõ" card on Home), pushed onto the Home tab's nav, and hides `ILBottomNavBar` while
shown.

- `.goBack` — back button on the header: `ILBellCoordinator` pops the screen and `finish()`.

## Known gaps / not implemented yet

- **Audio plays, but no per-session volume / sound picker** — strikes now play real audio (bundled
  `bell_strike.m4a` + `mo_strike.m4a` through `ILPracticeSoundPlayer`), but there is no user-facing
  control for volume or choosing a different bell/mo sound yet.
- **Session state is not persisted** — mode/preset/rhythm and counters reset on every open (same
  as Mala); a local Repository (UserDefaults/Core Data) would be added alongside a real need.
- The steady-rhythm timer and the roll sequence are implemented but their timing is not unit-tested
  (they use `Timer`/`DispatchQueue` side effects); the pure decisions behind them are covered by
  the UseCase tests.
- Counter labels ("Tiếng mõ N" / "Tiếng chuông N") render the number in the same weight as the
  label — the design bolds the count separately (minor).
- Edge-swipe-back (from `BaseNavigationController`) pops without going through `.goBack`, so the
  child coordinator is only removed on the explicit back button — same limitation as the other
  pushed screens.
- No UI test — not requested.
